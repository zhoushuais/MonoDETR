# MonoDETR 命令速查

直接复制执行。背景和坑见 `常用命令.md`。

## 0. 每次开始

```bash
conda activate monodetr
cd /root/MonoDETR
```

## 1. 训练

```bash
bash train.sh configs/monodetr.yaml <实验名>
```

## 2. 测试 / 评估

```bash
bash test.sh configs/monodetr.yaml <实验名>
```

## 3. tmux 后台训练

```bash
tmux new -s mono            # 新建会话

# 会话内
conda activate monodetr
cd /root/MonoDETR
bash train.sh configs/monodetr.yaml <实验名>

# 分离：Ctrl+b 然后按 d
```

```bash
tmux ls                     # 列出会话
tmux attach -t mono         # 回到会话
tmux attach -t mono -d      # 强制接管
tmux kill-session -t mono   # 结束指定会话
tmux kill-server            # 结束全部（慎用）
```

```
Ctrl+b d        分离
Ctrl+b c        新建窗口
Ctrl+b n / p    下 / 上一个窗口
Ctrl+b 0-9      切到指定窗口
Ctrl+b [        滚动模式（q 退出）
Ctrl+b %        左右分屏
Ctrl+b "        上下分屏
Ctrl+b x        关闭当前窗格
```

## 4. 查看进度

```bash
tail -f /root/gpufree-data/output/<实验名>/train.log.*
ls -lh /root/gpufree-data/output/<实验名>/
watch -n 2 nvidia-smi
ls /root/gpufree-data/output/
```

## 5. 实验管理

```bash
git add -A && git commit -m "exp: 改动说明"     # 每次实验前提交

# 对比两个实验的参数
diff /root/gpufree-data/output/<实验A>/config.yaml \
     /root/gpufree-data/output/<实验B>/config.yaml

rm -rf /root/gpufree-data/output/<实验名>       # 删掉某个实验
```

## 6. 改超参做对比实验

```bash
cp configs/monodetr.yaml configs/monodetr_lr2x.yaml    # 不动基线
bash train.sh configs/monodetr_lr2x.yaml lr2x_test
```

## 7. 改代码做改进实验

```bash
git checkout -b exp/<分支名>
# 改代码 ...
git add -A && git commit -m "exp: 改动说明"
bash train.sh configs/monodetr.yaml <实验名>
```

## 8. 重编译 CUDA 算子

```bash
cd /root/MonoDETR/lib/models/monodetr/ops
python setup.py build_ext --inplace
cp MultiScaleDeformableAttention*.so /opt/conda/envs/monodetr/lib/python3.8/site-packages/

# 验证（两行都 True 即正常）
python -c "import test; test.check_forward_equal_with_pytorch_double(); test.check_forward_equal_with_pytorch_float()"
```

## 11. 关键参数（configs/monodetr.yaml）

```
dataset.root_dir      /root/gpufree-data/KITTI
dataset.batch_size    8
dataset.writelist     ['Pedestrian', 'Car', 'Cyclist']
trainer.accum_steps   2          # 等效 batch 16
trainer.gpu_ids       '0'
trainer.save_path     /root/gpufree-data/output
trainer.max_epoch     195
optimizer.lr          0.0002
random_seed           444
```
